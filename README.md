# RIPPLE — 世界経済 What-if エンジン

**問いから始める、オープンな世界システムのストレス分析ワークベンチ。** 何が起きたら、世界のどの国・産業が最初に影響を受けるのかを、使ったデータと仮定を残しながら探索します。以前のThree.js 3Dネットワークビューは、探索用の2D世界アトラスと根拠台帳を中心としたWebアプリへ置き換えています。

> これは未来予測・倒産予測ではなく、限定された2020年産業連関表を使う条件付きの国×産業ストレス分析の試作です。表示される感度幅は入力範囲を振ったP10/P50/P90であり、事象確率、統計的な信頼区間、バックテスト済みの予測精度ではありません。

## アプリを使う

Webアプリ本体は [`viz/`](viz/) にあります。独立したスナップショット生成依存（Python 3、`numpy`、`pyshp`）を入れた上で、データベースとOECD係数ファイルがそろっている場所で一度スナップショットを生成し、その後アプリを起動します。

```bash
python3 -m pip install -r requirements-workbench.txt
python3 scripts/export_workbench.py
cd viz
corepack enable
pnpm install
pnpm dev
```

`pnpm build`で静的なWebアプリを生成します。`pnpm test`は条件計算の再現性や入力条件の整合を確認し、`pnpm check`はTypeScript型検査・モデル試験・本番ビルドをまとめて実行します。リポジトリrootでは`python3 -m unittest discover -s tests -p 'test_*.py'`も実行できます。これらの試験通過は、実体経済予測の検証・的中率を意味しません。

## 何が見えるか

- 国×産業の世界アトラス、ショック起点とは区別した下流の最初の波及順位、条件付き感度の要約を表示します。灰色は「影響なし」とは限らず、非収録や未接続を含みます。
- 日本上場企業のディレクトリは会社識別・分類・出典付き資本関係を検索します。産業平均を会社固有の損失へ変換しません。会社間の仕入・販売・貸付関係は未観測です。
- 台湾海峡封鎖、スエズ運河停止、銀行破綻、半導体工場停止、制裁、地震、港湾閉鎖、サイバー攻撃、パンデミック、原材料輸出禁止などを同じインターフェースから選べます。ただし、経路・与信・設備位置の観測がない事象は算定不可と明示します。利用者指定の国×産業生産中断に切り替えられる場合も、実際のイベント経路と区別します。
- 「原油価格2倍」は2020年ICIO分類のB05_06（石炭・原油・天然ガス等の集約）を用いる限定的な価格費用圧力proxyです。原油だけの供給ノード、実際の価格系列、企業別転嫁率は接続されていません。
- 結果は全入力仮定・モデル版・実際のコードrevision・SHA-256で識別したデータ版付きのScenario Bundle（JSON）として保存し、CSVとして書き出せます。比較用の履歴は使ったブラウザー内だけに保存します。

## モデルの範囲と限界

いま接続しているモデルは、OECD ICIO 2020の国×産業投入係数を用いた条件付きの多段伝播です。入力ショック範囲、代替調達、在庫、価格転嫁は実績として補わず、利用者仮定として表示します。全下流経路を収束させた価格や生産量モデル、需要反応、価格弾力性、稼働率、企業別調達フローはまだ実装していません。複数の波及は同じフローセルを二重計上せず、受け手の合計上限で飽和させます。

国・産業レベルの観測と会社レベルの関係を明確に分離します。資本関係を仕入・販売・信用関係の代わりにしません。産業連関による波及と会社取引による波及を足し合わせません。バックテスト、事象確率、倒産確率校正は未実施です。履歴の記録とモデルの予測性能は別物として扱います。

現在の静的アプリでは、UN Comtradeの生データ行、World Bankの価格時系列、航路の集計行を配布スナップショットに含めません。海峡・港・工場・企業間取引の線をデータがあるかのように描きません。該当ソースの利用許諾を確認してから更新してください。

以前の`viz/data/graph.json`と`viz/index.html`は`archive/legacy-3d/`に保管し、Three.jsの旧画面は現在のViteアプリから分離しています。`scripts/scenario_engine.py`と`backtest_calibrate.py`も歴史的なprototypeで、両方のCLI実行は無効化しています。それらの企業損失や「較正」出力を、現在のモデルの予測・実証済み精度として扱わないでください。現在の公開インターフェース、計算式、出典の境界は`viz/src/`とこのREADMEが対象です。
