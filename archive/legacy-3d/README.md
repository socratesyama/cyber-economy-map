# Archived 3D prototype

This folder preserves the earlier standalone Three.js view and the data exports it consumed. It is not loaded by the current Vite application under `viz/`. Its ownership graph, proxy edges, firm-level loss values, random completion of missing exposures, market-cap scaling and layout are historical prototype behavior—not observed procurement flows, validated economic losses or forecast evidence.

The current workbench and its model boundaries are documented in the repository-root `README.md`, `docs/data-sources.md` and `viz/src/`. `scripts/export_viz.py` can regenerate the old graph into this archive only; it must not be used as the current product data pipeline.
